# Slice 121: Compact action buttons and navigation

Make existing actions compact and consistent, with one top home/back navigation on short pages and preserved final returns on long pages.

- Standard tier; one requirement changed, PLT-4, refining three existing criteria (.2, .6, .7), with no new or retired IDs.
