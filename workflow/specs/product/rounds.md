# Test rounds

Planning area `RND`; no acceptance criteria or application features are implemented yet. See the [product spec](../PRODUCT-SPEC.md).

## Planned work

Test Coordinators prepare and publish rounds, manage criteria and cases, review results, request retests and close rounds. The [test-drafting AI feature](../ai/test-drafting.md) offers suggestions for review.

Before implementation, settle round states and permitted transitions, build references, availability to testers, published-case edits/versioning and closure rules. Results must remain tied to the build and criteria tested. Exact screens and fields remain open.
