## Agent workflow

Feature work in this repository follows the portable agent workflow in `agent-workflow/`. Read `agent-workflow/slice.md`, then `agent-workflow/project.md` for this repository's commands, folders and homes. It takes precedence over any other feature workflow described here; the rest of this file still applies.

**Profile.** Run `printenv AGENT_PROFILE`. If it prints `strong`, follow `agent-workflow/profiles/strong.md`; otherwise follow `agent-workflow/profiles/guarded.md`. Never choose a profile yourself, and name it at the start of your report.
