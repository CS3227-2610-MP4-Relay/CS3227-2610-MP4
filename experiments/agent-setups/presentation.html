Agent setups · #31

Experiment #31 · zheng-jj · October 2026

What does an agent workflow cost, and what does it buy?

We ran twelve ways of setting up a coding agent on two real Relay tasks, 74 runs in all, with everything else held fixed. Then we built a setup from what we learned and tested it on five models.

The short answer

Six findings

1

Every setup wrote correct code.

71/71 runs correct

2

Building in one session costs about half, and takes about half the time.

45–63% less

3

The money goes on hand-offs between agents.

about 55% of MP4's cost

4

The popular add-ons didn't pay off.

−19% to +10% on task 2

5

Methodology plugins are one session with extra steps.

same cost as one session

6

Sonnet is enough for this work.

$2.25 vs $8.97

So our ideal setup builds in one session and keeps one independent reviewer. It gives the same quality at about half MP4's cost.

Finding 3

The money goes on hand-offs

About 55% of an MP4 run's cost is subagents reading the repository again. The single-session setups barely pay this.

Finding 3

Why hand-offs are expensive

MP4: a new agent for each step

CoordinatorBuilderBuilderVerifierSecurity reviewerBuilder (repair)Verifier (recheck)

Each subagent starts empty. It reads the rules, the specs and the code again, and pays to cache them again. MP4 started 8–12 of them per run.

One session: read once

One session: spec, tests, code, docsOne reviewer

The session keeps what it has read for the whole build. Only the reviewer starts fresh, and that fresh view is the point of having it.

Finding 4

The add-ons didn't pay off

On task 1 they looked 32–49% less than MP4. On task 2 the saving was gone: −19% to +10%. None changed quality.

Task 1 · #68Task 2 · #16

What actually moved the cost was how many subagents the coordinator started, not the add-on.

Finding 4

The add-ons, one at a time

caveman

Promise: shorter output.

Output fell 33% on task 1 and 10% on task 2. But output is only about a fifth of the bill.

Small effect

ponytail

Promise: the smallest change.

Leaner tests on task 1, same quality. The saving didn't hold on task 2.

No lasting effect

headroom

Promise: compressed context.

It compressed only 0.9–1.1% of traffic, and it routes your API key through a proxy.

Not worth the risk

Finding 5

Methodology plugins are one session with extra steps

superpowers

$4.14 and $5.60. Planning and test-first habits, built in one session. One review subagent.

spec-kit

$4.40 and $5.48. A spec, plan and task list first, then one session builds. No independent review.

MP3: six roles

$5.77 and $11.88. More roles and more tests, but nothing extra found. On task 2 it cost as much as MP4.

Solo: one session plays every role

$3.35, the cheapest Opus setup on task 1. Its weakness: it reviews its own work.

Costs are medians for task 1 and task 2 on Opus.

AGENT_PROFILE

strong for Opus or Sonnet: the steps as written.

guarded for anything else, or when unset: a checklist, hard stops, and numbers only from commands actually run.

One file per project

project.md says how to verify, where specs, docs and accepted risks live, and the size budget. Everything else is the same in every repository and every tool.

Use it

The package is in experiments/agent-setups/ideal/v6/. It adds one workflow folder, a block in AGENTS.md, and small adapters for each tool.

Conclusion

Takeaways

  1. Build in one session.
  2. Keep exactly one independent reviewer.
  3. Try the cheaper model first.
  4. Give weaker models a checklist, not freedom.
  5. Before review, check that specs, tests and decisions still agree.
  6. Write the project's facts down once.

Conclusion

Skip, or test on your own work first

  • Token-saving add-ons and proxies.
  • Adding more agent roles.
  • Letting the model choose its reviewer or its profile.
  • Trusting a result from one task.

Conclusion

Limits

  • Two tasks, in one Django project, with the decisions given up front.
  • One to three runs per setup, so only large differences count.
  • Quality was at the ceiling, so this mostly measures cost and time.
  • Opus wrote the hidden tests and reviews, and built most candidates.
  • Costs are list prices; a subscription bills differently.
