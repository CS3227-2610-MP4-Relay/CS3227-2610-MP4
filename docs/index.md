Relay is a beta-testing portal for small software teams. Test Coordinators prepare, publish and review test rounds; Beta Testers run checks, record observations and retest fixes. Coordinators can draft test cases with AI, and testers can get AI feedback on a draft observation. The software being tested runs outside Relay.

## Project status

Relay currently runs locally. See the [User Guide](https://github.com/CS3227-2610-MP4-Relay/CS3227-2610-MP4/blob/main/docs/UserGuide.md) for available workflows and the [Developer Guide](https://github.com/CS3227-2610-MP4-Relay/CS3227-2610-MP4/blob/main/docs/DeveloperGuide.md) for setup. Public application hosting remains planned.
