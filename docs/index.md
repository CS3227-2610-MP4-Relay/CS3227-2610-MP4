Relay is a planned beta-testing portal for small software teams. Test Coordinators prepare test rounds; Beta Testers run checks, record observations and retest fixes. The software being tested runs outside Relay.

## Project status

The repository and development workflow are being set up. The application and public deployment are not available yet.
