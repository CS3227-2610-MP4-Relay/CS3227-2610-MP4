Relay is a beta-testing portal for small software teams. Test Coordinators prepare and publish test rounds; the planned Beta Tester workflow will let testers run checks, record observations and retest fixes. The software being tested runs outside Relay.

## Project status

Relay currently runs locally. See the [User Guide](https://github.com/CS3227-2610-MP4-Relay/CS3227-2610-MP4/blob/main/docs/UserGuide.md) for available workflows and the [Developer Guide](https://github.com/CS3227-2610-MP4-Relay/CS3227-2610-MP4/blob/main/docs/DeveloperGuide.md) for setup. Tester result submission, AI features and public application hosting remain planned.
